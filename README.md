# docs

The Permio docs at [docs.perms.io](https://docs.perms.io), built with [Starlight](https://starlight.astro.build)
(Astro) and themed to match [perms.io](https://perms.io).

```bash
npm install
npm run dev     # http://localhost:4321
npm run build   # regenerates public/llms-full.txt, then builds dist/
```

- Pages are in `src/content/docs/` (MDX). The sidebar order is in `astro.config.mjs`.
- `src/snippets/hosts.mdx` holds the API hosts; pages include it with `<Hosts />`, so a host change is a one-file edit.
- Theme: `src/styles/theme.css`, plus overrides in `src/components/` (header, hero, endpoint badges, dark-only theme).
- `public/llms-full.txt` is generated by `scripts/build_llms_full.py` from the pages in sidebar order;
  `npm run check:llms` fails if the committed copy is out of date. The deploy runs the script with
  `--header-url https://perms.io/llms-header.md`, which puts the header perms.io publishes (summary, current SDK
  versions, pricing) at the top of `llms-full.txt` and writes `public/llms.txt` as that header plus the hand-written
  `llms-index.md`. Facts in the header belong in the website repo (`src/lib/content.ts`), not here.

Pull requests check that `public/llms-full.txt` is up to date and build the site; the build fails on broken internal
links or anchors (`starlight-links-validator`). Pushing to `main` (or a `facts-updated` dispatch from the website deploy) builds the site and force-pushes `dist/` to the
`gh-pages` branch, which GitHub Pages serves (see `.github/workflows/deploy.yml`).
