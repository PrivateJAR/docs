## Key features

<CardGrid>
	<Card title="Resource-level RBAC" icon="padlock">
		Grant access to individual objects, such as `/projects/42` or `/documents/42/comments/7`, not just to whole types.
	</Card>
	<Card title="Hierarchical inheritance" icon="list-format">
		A grant on `/documents` applies to `/documents/42` and everything beneath it, including resources created later.
		The `_` wildcard segment lets one grant cover a whole level. See [Resources and inheritance](/concepts/resources/).
	</Card>
	<Card title="Groups" icon="puzzle">
		Grant to a group such as `group:editors` once, and every member holds the grant. See [Groups](/concepts/groups/).
	</Card>
	<Card title="Bring your own authentication" icon="approve-check">
		Permio only does authorisation. Principals are whatever IDs your app already uses, so it works with any login system.
	</Card>
	<Card title="API first" icon="seti:json">
		One REST/JSON, gRPC and gRPC-web API, and a [TypeScript SDK](/sdk/typescript/) with check helpers, typed errors,
		retries and iterators. See the [API reference](/api-reference/).
	</Card>
	<Card title="Dashboard" icon="laptop">
		Manage projects, permissions, roles, grants and API keys at [app.perms.io](https://app.perms.io).
	</Card>
</CardGrid>

## For AI assistants

If you use a coding assistant or an LLM, point it at these files:

- [`llms.txt`](/llms.txt) (`https://docs.perms.io/llms.txt`): an index of every page on this site, with a one-line
  description of each.
- [`llms-full.txt`](/llms-full.txt) (`https://docs.perms.io/llms-full.txt`): the concepts, quickstart, TypeScript SDK
  and API reference in one Markdown file, to load straight into the model's context.

For example, give your assistant this prompt:

```text title="Prompt"
Add Permio permissions to this app using the `permio` npm package. Docs: https://docs.perms.io/llms.txt
```

Install it with `npm install permio`. See the [TypeScript SDK](/sdk/typescript/).
