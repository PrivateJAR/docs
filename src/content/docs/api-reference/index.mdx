The perms.io API has two services:

| Service | Proto | What it does |
| --- | --- | --- |
| [Permissions](/api-reference/permissions/) | `permio.permissions.v1.PermissionsService` | Permissions, roles, grants and **checks**. This is the service your application calls. |
| [Organisations](/api-reference/organizations/) | `permio.organisation.v1.OrganisationService` | Organisations, projects, API keys and team members. Mostly used by the dashboard. |

Both are defined in Permio's protobuf definitions. The same host serves them as REST/JSON, gRPC and gRPC-web.

<Hosts />

## Protocols

| Protocol | How to call it |
| --- | --- |
| **REST/JSON** | The HTTP method and path listed for each RPC in this reference, for example `POST $PERMIO_API/permissions-service/v1/permissions/check`. Request bodies accept the proto field names (`project_name`). Responses use camelCase JSON names (`missingPermissions`) and leave out fields that have default values. |
| **gRPC** | Connect to the host on port 443 with TLS, for example `api.perms.io:443`, and send the key as `authorization` metadata. The [Go](/sdk/go/), [Python](/sdk/python/), [Rust](/sdk/rust/) and [Java](/sdk/java/) SDKs use it. |
| **gRPC-web** | The protocol the [TypeScript SDK](/sdk/typescript/) uses. It works from servers, edge runtimes and browsers. |

For `GET` and `DELETE` requests over REST, fields that aren't in the path go in the query string. Nested fields use
dot notation, for example `?project_name=default&pagination.limit=50`.

## Authentication

Every request needs an [API key](/concepts/api-keys/), sent as a bearer token:

```
Authorization: Bearer perms_...
```

Keys are 44 characters long: `perms_`, 32 random base62 characters and a 6-character checksum. A key is shown once,
when you create it in the dashboard. Only a hash of it is stored, and you can invalidate it at any time. Older JWT
API keys are still accepted.

A key acts within its own **project**. Your organisation is worked out from the key, so permission requests don't
include an organisation ID. A key gets its own grants on its project: by default **check** access, which allows
`Check`, the access queries and the read-only calls. See [Access levels](/concepts/api-keys/#access-levels).

## Errors

A **denied check is not an error**. `Check` returns success with `passed: false` and a list of
`missing_permissions`. Errors mean that the request itself could not be carried out:

| gRPC status | HTTP | Meaning |
| --- | --- | --- |
| `INVALID_ARGUMENT` (3) | 400 | Malformed input: an invalid resource URI, an empty permissions list, a bad project name, more than 100 items in a check, and so on. |
| `UNAUTHENTICATED` (16) | 401 | The API key is missing, malformed, unknown or invalidated. |
| `PERMISSION_DENIED` (7) | 403 | The **API key** isn't allowed to make this call. For example, a key without `permission.check` calling `Check`, or a check-only key creating a role. The message lists what is missing. |
| `NOT_FOUND` (5) | 404 | The permission, role, group or other entity doesn't exist. Also returned when a `group:<slug>` principal names a group that doesn't exist. |
| `ALREADY_EXISTS` (6) | 409 | A group with this name already exists in the project. |
| `INTERNAL` (13) | 500 | Something went wrong on our side. |
| `UNAVAILABLE` (14) | 503 | The service is temporarily unavailable. Safe to retry for reads. |

Over REST, the error body carries the gRPC code and a message:

```json
{"code": 16, "message": "invalid api key"}
```

Over gRPC and gRPC-web, the code arrives as `grpc-status` and the text as `grpc-message`.

<TabItem label="TypeScript">


The [TypeScript SDK](/sdk/typescript/) (`npm install permio`) is the recommended client.
Besides the check helpers, it exposes every RPC on this page through `permio.permissions` and
`permio.organisations`.

</TabItem>
<TabItem label="cURL">


Every RPC has a REST path, listed with each method in this reference.

```bash
curl -X POST "$PERMIO_API/permissions-service/v1/permissions/check" \
  -H "Authorization: Bearer $PERMIO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"project_name": "default", "principal_id": "alice", "resource_uris": ["/documents/42"], "permissions": ["document.read"]}'
```

</TabItem>
<TabItem label="Go">


The [Go SDK](/sdk/go/) (`go get github.com/PrivateJAR/permio-go@latest`, Go 1.24+) is the recommended client.
Besides the check helpers, it exposes every RPC on this page through `client.Permissions()` and
`client.Organisations()`, the generated gRPC clients with auth, timeouts, retries and typed errors applied.

```go
import permio "github.com/PrivateJAR/permio-go"

client, err := permio.New(permio.Options{
    APIKey:  os.Getenv("PERMIO_API_KEY"),
    Project: "default",
})
// handle err
defer client.Close()

allowed, err := client.Check(ctx, "alice", "document.read", "/documents/42")
```

</TabItem>
<TabItem label="Python">


The [Python SDK](/sdk/python/) (`pip install permio`) gives you a synchronous `Permio` client and an asyncio
`AsyncPermio` client with the same methods. Besides the check helpers, both expose every RPC on this page through
`permio.permissions` and `permio.organisations`, with the generated messages in `permio.raw`.

```python
from permio import Permio

permio = Permio(api_key=api_key, project="default")  # api_key defaults to $PERMIO_API_KEY

permio.check("alice", "document.read", "/documents/42")  # True or False
```

</TabItem>
<TabItem label="Rust">


The [Rust SDK](/sdk/rust/) (crate `permio`) is the recommended client. It isn't on crates.io yet, so depend on
the Git repository. Besides the check helpers, it exposes every RPC on this page through `permio.raw_permissions()`
and `permio.raw_organisations()`, with authentication, timeouts and retries already applied.

```toml
[dependencies]
permio = { git = "https://github.com/PrivateJAR/permio-rust" }
tokio = { version = "1", features = ["macros", "rt-multi-thread"] }
```

```rust
let permio = permio::Client::builder()
    .api_key(api_key) // defaults to the PERMIO_API_KEY env var
    .project("default")
    .build()?;

let allowed = permio.check("alice", "document.read", "/documents/42").await?;
```

</TabItem>
<TabItem label="Java">


The [Java SDK](/sdk/java/) (`io.perms:permio`, Java 11+) wraps the check, access-query, grant and group RPCs, and
exposes every RPC on this page as generated gRPC stubs through `permio.raw()`. It is coming soon to Maven Central.

```java
import io.perms.Permio;

Permio permio = Permio.builder()
    .apiKey(System.getenv("PERMIO_API_KEY"))
    .project("default")
    .build();

boolean allowed = permio.check("alice", "document.read", "/documents/42");
```

</TabItem>

Field names in this reference are the proto names (`project_name`). The generated clients use their language's
convention: `ProjectName` in Go, `project_name` in Python and Rust, `projectName` in TypeScript, and
`setProjectName` / `getProjectName` in Java.

### Other languages

Permio is a gRPC and REST/JSON API, so you can use it from any language:

- **Generate a client** from Permio's public protobuf definitions with your language's gRPC tooling. The public
  protos repository is coming soon.
- **Call the REST API** with any HTTP client, using the paths listed for each RPC in this reference and the
  `Authorization: Bearer` header described in [Authentication](#authentication).
