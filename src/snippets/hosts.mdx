<Aside type="note" title="API host">

The API is at `https://api.perms.io`. The examples on this site read the host from a `PERMIO_API` shell variable:

```bash
export PERMIO_API=https://api.perms.io
export PERMIO_API_KEY=perms_...   # your API key
```

</Aside>
